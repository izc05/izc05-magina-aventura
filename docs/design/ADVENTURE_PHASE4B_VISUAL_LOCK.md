# Aventura Mágina — referencia visual aprobada Fase 4B

**Estado:** referencia visual canónica de dirección / aprobada por el propietario el 2026-09-20.

Esta referencia fija el norte visual de la experiencia Android de aventura. No declara que las pantallas estén implementadas píxel a píxel ni sustituye los contratos funcionales del Adventure Engine.

## Dirección visual que debe preservarse

- identidad Mágina Aventura con verde olivo, crema, fotografía de Sierra Mágina y sensación premium;
- selección de rutas con tarjetas fotográficas;
- mapa protagonista con trazado, checkpoints y discoveries claramente diferenciados;
- HUD durante la ruta con siguiente checkpoint, tiempo/distancia y acceso rápido a pausa/mapa;
- estados de checkpoint alcanzado y descubrimiento con presentación narrativa y recompensa visual;
- pausa/recovery explícitos, con sensación de que el progreso está protegido;
- pantalla de finalización con resumen de tiempo, distancia, checkpoints y descubrimientos;
- navegación limpia, botones grandes y legibles para uso exterior;
- DEV/Test Harness claramente distinguido del contenido real y nunca visible en producción.

## Regla para agentes

Manus, Antigravity, Codex u otros agentes deben usar esta referencia como objetivo visual para la experiencia de aventura. Cualquier desviación fuerte de jerarquía, lenguaje visual, mapa/HUD o interacción debe justificarse antes de sustituir esta dirección.
